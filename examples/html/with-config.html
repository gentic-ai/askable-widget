Askable Widget - Configured Example

Configuration Options Used

  • data-position="bottom-left" - Widget appears on bottom-left
  • data-language="en" - English language
  • data-auto-open="true" - Auto-open widget
  • data-auto-open-delay="3000" - Wait 3 seconds before auto-opening

Custom Configuration

This example demonstrates how to configure the widget with custom options:

  • Position: Bottom-left corner
  • Language: English
  • Auto-open: Enabled with 3 second delay

Replace YOUR_SITE_ID with your actual site ID.
