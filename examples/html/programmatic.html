How It Works

This example shows how to initialize and control the widget using JavaScript:

// Initialize widget programmatically
const widget = window.initAskableWSWidget({
  siteId: 'YOUR_SITE_ID',
  position: 'bottom-right',
  language: 'en'
});

// Open widget and start voice session
widget.openAndStart();

// Destroy widget
widget.destroy();

Note: Replace YOUR_SITE_ID with your actual site ID in the script below.
